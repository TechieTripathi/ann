# Artificial Neural Networks — lecture series

Three Slidev decks sharing one design system.

| Deck | Entry | Pages | Length |
|---|---|---|---|
| **Lecture 1** — Artificial Neural Networks | `lecture-01-ann.md` | `pages-01-ann/` | 31 slides, ~90 min |
| **Lecture 2** — Backpropagation | `lecture-02-backpropagation.md` | `pages-02-backpropagation/` | 31 slides, ~90 min |
| **Lecture 3** — From Hand to Framework | `lecture-03-pytorch.md` | `pages-03-pytorch/` | 9 slides, Ch. 1 of 5 |

```bash
npm install
npm run dev        # Lecture 1  -> http://localhost:3030
npm run dev:02     # Lecture 2
npm run dev:03     # Lecture 3
npm run verify     # re-check every number in Lecture 2 (add --torch to cross-check with autograd)
npm run verify -- --nn    # also check the nn.Sequential path Lecture 3 puts on screen
```

## Shared, not duplicated

`styles/index.css`, `components/`, and `global-bottom.vue` are picked up by Slidev for **any**
entry file in this directory (`userRoot` is the entry file's folder). All three decks therefore
share one palette, one `<Callout>`, and one footer. Keeping every entry file at the repo root is
what makes that work — moving a deck into a subfolder would force a duplicate copy of the design
system.

## The numbers in Lectures 2 and 3

Every figure in the worked example is generated by `scripts/verify-numbers.py` and cross-checked
against PyTorch autograd in float64. **If a slide disagrees with that script, the slide is wrong.**

Lecture 3 prints framework output on the slides, so the same script also verifies the
`nn.Sequential` path it shows — the gradients, the parameters after one `opt.step()`, and the
`nn.MSELoss()` discrepancy — under `--nn`.

## Deployment

`.github/workflows/deploy.yml` builds all three decks into one GitHub Pages artifact:

```
/                 landing/index.html   course index
/lecture-01/      Lecture 1
/lecture-02/      Lecture 2
/lecture-03/      Lecture 3
```

All are built with `--router-mode hash`, because GitHub Pages only serves a **root** `404.html` —
a per-deck SPA fallback in a subdirectory is never used, so history-mode deep links would 404.
